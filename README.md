## هدف محصول

در مدل سنتی توزیع مواد غذایی، هر فروشگاه روزانه با چند ویزیتور و پخش‌کننده سروکار دارد: قیمت‌ها شفاف نیست،
سفارش‌گیری تلفنی یا کاغذی است و هزینه توزیع بالاست. این دمو نشان می‌دهد که با اتصال مستقیم تأمین‌کننده به
فروشگاه روی یک پلتفرم واحد:

| شاخص | مدل سنتی | پلتفرم بازارعمده |
| --- | --- | --- |
| هزینه هر سفارش‌گیری | ۴۲۰٬۰۰۰ تومان | زیر ۹۰٬۰۰۰ تومان |
| زمان ثبت تا تحویل | ۳ تا ۷ روز | ۲۴ تا ۷۲ ساعت |
| شفافیت قیمت | قیمت موردی | نرخ‌نامه پله‌ای آنلاین |
| کاتالوگ در دسترس | محدود به موجودی پخش | کاتالوگ کامل همه برندها |
| تحلیل خرید فروشگاه | بدون داده | داشبورد BI اختصاصی |

## ویژگی‌ها

### پنل مشتری (فروشگاه، رستوران، عمده‌فروش)

- **کاتالوگ کامل عمده** با فیلتر برند، دسته‌بندی، کشور مبدأ، محدوده قیمت، موجودی و کالاهای تخفیف‌دار
- **جست‌وجوی هوشمند** بر پایه نام فارسی/لاتین، بارکد، مترادف‌ها و نام برندها
- **نرخ‌نامه آبشاری (Waterfall Pricing)** با نمایش پله‌های قیمت و پیشنهاد افزایش کارتن
  («۲ کارتن دیگر اضافه کن → ۳٪ ارزان‌تر»)
- **سبد خرید عمده** با محاسبه زنده تخفیف پله‌ای، تخفیف نقدی، تخفیف کمپین، تخفیف VIP، مالیات و هزینه ارسال
- **پیش‌فاکتور و فاکتور رسمی** با خروجی PDF و چاپ (ساخته‌شده در مرورگر)
- **فرایند تسویه اعتباری/چکی/اقساطی/آنلاین** با شبیه‌سازی درگاه پرداخت
- **سفارش‌های من، پیگیری سفارش، مرجوعی، امضای دیجیتال تحویل (POD) و QR سفارش**
- **علاقه‌مندی‌ها، لیست مقایسه کالا، بازدیدهای اخیر و پیشنهاد کالای مکمل**
- **استعلام قیمت (RFQ)** برای سفارش‌های بزرگ با پیگیری وضعیت
- **خرید گروهی هم‌صنفان و سفارش دوره‌ای (اشتراک خرید)**
- **کیف پول، سقف اعتبار، باشگاه مشتریان، امتیاز و کد دعوت (Referral)**
- **گفت‌وگوی پشتیبانی** با پاسخ‌های هوشمند مبتنی بر قواعد
- **آکادمی خرده‌فروش، انجمن صنفی، دستور پخت و وبینار**
- **پایداری و مسئولیت اجتماعی**: کاهش ضایعات، اهدای کالای نزدیک انقضا و ردپای کربن
- **اپلیکیشن نمایشی ویزیتور و اپلیکیشن راننده** برای مشاهده مسیر و سفارش‌ها

### پنل مدیریت

- **داشبورد تحلیلی فروش** با نمودار درآمد، سفارش، مرجوعی و سهم دسته‌بندی‌ها
- **مدیریت سفارش‌ها** با تغییر وضعیت، فاکتور، یادآوری تسویه و خروجی CSV
- **مدیریت مشتریان** با اعتبارسنجی، تأیید مدارک، سقف اعتبار و تحلیل ریسک ریزش
- **مدیریت کاتالوگ**: برندها، کالاها، پله‌های قیمت، MOQ، بسته‌بندی، تصاویر و وضعیت انتشار
- **مدیریت انبار**: موجودی، بچ و انقضا (FEFO)، کنترل کیفیت، تأمین‌کنندگان و فراخوان کالا
- **لجستیک**: تخصیص راننده، مسیریابی چندتوقفی، رهگیری محموله و گواهی تحویل (POD)
- **فروش میدانی**: سرنخ‌ها (Leads)، قیف فروش، ویزیت‌ها و تحلیل حذف ویزیت فیزیکی
- **قرارداد قیمت پیمانی** با تعهد حجمی، امضای دیجیتال و پایش تحقق
- **کمپین و آفر**: کمپین فروشگاهی، پالتی، فصلی، اولین سفارش و VIP
- **داشبورد هوشمند (BI)**: تحلیل سبد کالا، RFM، مقایسه سگمنت‌ها و پیش‌بینی ریزش
- **گزارش‌گیری** در ۶ گزارش کلیدی با خروجی CSV، چاپ و PDF
- **پشتیبانی و تیکت** با کانال‌های گفت‌وگو و امتیاز رضایت (NPS)
- **کاربران، نقش‌ها و RBAC** با ۷ نقش و مجوزهای تفکیک‌شده
- **لاگ عملیات (Audit Trail)** برای تمام تغییرات کاتالوگ، قیمت، سفارش و کاربران
- **یکپارچه‌سازی و API** (حسابداری، ERP، WMS، TMS، پیام‌رسان، مودیان) + مستندات API و وب‌هوک
- **انطباق و مجوزها**: پروانه IRC، حلال، ارگانیک، ردیابی بچ و امنیت (2FA/SSO)
- **تنظیمات پلتفرم**: مالیات، ارسال، شرایط تسویه، مدل‌های کسب‌وکار و بازنشانی دمو

## ماژول شوینده و بهداشتی

> این ماژول توسط **کارن سافت (Karen-soft.ir)** به‌صورت کاملاً ماژولار و با امکان فعال/غیرفعال‌سازی (Feature Flag) طراحی شده است. همه توانمندی‌های بخش
> غذایی (کاتالوگ، پنل مشتری، پنل ادمین، آفرها، قیمت‌گذاری، لجستیک و گزارش‌گیری) در حوزه شوینده و بهداشتی بازتولید شده و به قابلیت‌های تخصصی این صنف
> نیز تجهیز شده است.

### گستره دامنه

- **صنایع و برندها:** بیش از ۵۰ برند ایرانی و خارجی شامل گلرنگ، پاکسان، پاکشو، ساینا، تولی‌پرس، یونیلیور، P&G، Henkel، Reckitt، Colgate، J&J،
  Kimberly-Clark و… در پوشه‌های `/data/detergent/` (شوینده + خانه و آشپزخانه) و `/data/hygiene/` (بهداشتی) نگهداری می‌شوند.
- **دسته‌بندی‌ها:** شوینده (پودر ماشین، مایع لباسشویی، مایع ظرفشویی، پودر دستی، سفیدکننده، جرم‌گیر، لکه‌بر، نرم‌کننده، شامپو فرش، شیشه‌شور،
  چربی‌زدا، ضدعفونی‌کننده سطوح)؛ بهداشتی (صابون، شامپو، نرم‌کننده مو، خمیردندان، مسواک، دهان‌شویه، دستمال کاغذی و مرطوب، پوشک، نوار بهداشتی،
  ژل ضدعفونی دست، ماسک، مراقبت پوست، تیغ، آرایشی پایه)؛ خانه و آشپزخانه (دستکش، اسفنج، کیسه زباله، فویل، سلفون، ظروف یکبار مصرف).
- **فیلترهای تخصصی پنل مشتری:** کاربرد، رایحه (بی‌رایحه/لیمو/گل/وانیل/صابونی)، حجم و وزن (ساشه تا گالن ۲۰ لیتری)، ضدباکتری، مناسب پوست حساس،
  ایمن برای کودک، طبیعی/گیاهی، بسته‌بندی عمده — به‌همراه دسته‌بندی هوشمند (پرکاربرد/پرفروش/جدید/آفر ویژه) و مرتب‌سازی بر اساس «بهترین قیمت هر واحد».
- **قیمت‌گذاری:** همان آبشار قیمتی بخش غذایی + تخفیف نقدی + پله‌های حجمی بر اساس تعداد کارتن (مثلاً ۱۰ تا ۵۰ / ۵۱ تا ۲۰۰ / ۲۰۱ به بالا) + آفرهای
  کمپینی و فصلی + قیمت VIP + قرارداد زنجیره‌ها؛ نمایش «قیمت هر لیتر/هر کیلو» و راهنمای ارتقا پله («۴ کارتن دیگر اضافه کن → ۵٪ ارزان‌تر + ارسال رایگان»).
- **باندل و پیشنهاد هوشمند:** پک‌های ترکیبی مثل «پک خانه‌تکانی»، «پک نوروز»، «ست بهداشت بانوان»، «مراقبت مو حرفه‌ای»، «ضدعفونی پاییزه» به‌همراه
  تحلیل سبد خرید («فروشگاه‌های مثل شما این ست را خریدند») و پیشنهاد مکمل (شامپو + نرم‌کننده).
- **مقایسه فنی:** مقایسه کنار هم محصولات از نظر قدرت پاک‌کنندگی، غلظت، pH، رایحه، ایمنی پوست و قیمت هر لیتر/کیلو.
- **پنل ادمین تفکیکی:** مدیریت برندها با تگ صنعت (شوینده/بهداشتی/مخلوط)، دسته‌بندی درختی، ویژگی‌های تخصصی، مجوزها و استانداردها (پروانه بهداشت،
  پروانه ساخت، IRC، ISIRI، حلال، ارگانیک، Cruelty-Free، Child-safe، قابل بازیافت)، مدیریت کمپین‌های فصلی (خانه‌تکانی، بازگشایی مدارس، شب عید)،
  گزارش تفکیکی فروش (شوینده vs بهداشتی vs غذایی)، مدیریت موجودی اقلام حجیم (گالن/کارتن بزرگ)، هشدار انقضای محصولات بهداشتی، پیشنهاد قیمت بهینه
  بر اساس نرخ رقبا و محاسبه هزینه ارسال بر اساس وزن/حجم.
- **لجستیک تخصصی:** توزین دقیق، بسته‌بندی ویژه (گالن/کارتن بزرگ)، زنجیره سرد برای محصولات آرایشی و بهداشتی، رهگیری بچ و تاریخ انقضا، انبارداری
  ایمن مواد شیمیایی (تفکیک سفیدکننده از اقلام بهداشتی).
- **رابط کاربری:** هویت بصری متمایز (شوینده آبی/سبز، بهداشتی صورتی/سفید)، نشان‌های تصویری (ضدباکتری، بوی ماندگار، مناسب پوست حساس، بدون رنگ)،
  آیکون‌های سریع ویژگی‌ها، فیلترهای چک‌باکسی، نمایش قیمت واحد و نشان‌های 🌿 💧 👶 🌸 💰.
- **Feature Flag:** فعال/غیرفعال‌سازی کامل ماژول از «تنظیمات → ماژول‌های کاتالوگ» یا «پنل ماژول شوینده و بهداشتی»؛ با غیرفعال شدن، محصولات، برندها و
  آفرهای همان بخش از کل پلتفرم پنهان می‌شوند. داده‌های ماژول در پوشه‌های جداگانه `/data/detergent/` و `/data/hygiene/` ساختاری مشابه بخش غذایی
  دارند و کد ماژول در `src/modules/dh/` ایزوله نگهداری می‌شود.

### مسیرهای ماژول

| مسیر | کاربرد |
| --- | --- |
| `/#/dh` | پنل مشتری ماژول شوینده و بهداشتی |
| `/#/admin/dh` | پنل ادمین تفکیکی ماژول (Feature Flag، برندها، مجوزها، گزارش‌ها) |
| `/data/detergent/` و `/data/hygiene/` | داده‌های نمونه: دسته‌ها، برندها، کالاها، آفرها، باندل‌ها، مجوزها، تأمین‌کنندگان |
| `src/modules/dh/` | لایه مستقل ماژول: تایپ‌ها، ساخت داده، قیمت‌گذاری، فیلترها، تحلیل‌ها، کامپوننت‌ها |

  فصلی بودن و نام فصل (نوروز، رمضان، بازگشایی مدارس، تابستان، زمستان) + دسته‌بندی هوشمند (پرفروش/جدید/فصلی/اقتصادی/پریمیوم/آفر ویژه).
- **ویژگی‌های تخصصی محصول (Product):** جنس، ابعاد، وزن، ولتاژ/توان، ظرفیت، سازگاری، نوع حیوان، گروه سنی، فصلی بودن و نام فصل.
- **قیمت‌گذاری:** همان آبشار قیمتی + تخفیف نقدی + پله حجمی (تعداد → قیمت) + آفر کمپین (نوروز، بازگشایی مدارس، رمضان) + VIP + قرارداد قیمت پیمانی +
  نرخ‌نامه چندواحدی (تک‌عدد/بسته/کارتن/شرینک/پالت) با نمایش قیمت هر عدد و هر کیلو + ناگ «۳ کارتن دیگر اضافه کن → ۴٪ ارزان‌تر».
- **باندل و پیشنهاد هوشمند:** «پک بازگشایی مدارس» (دفتر + خودکار + مداد + پاک‌کن)، «پک نوروزی»، «پک افطاری»، «پک شارژ همراه»، «پک آشپزخانه نو»، «پک
  سلامت پت» + پیشنهاد «فروشگاه‌هایی مثل شما این ست را خریدند» + مقایسه فنی کنار هم (جنس، ابعاد، ظرفیت، توان، سازگاری، قیمت هر عدد).
- **پنل ادمین تفکیکی:** مدیریت برندها با تگ صنعت (لوازم‌التحریر، باتری، موبایل، برقی، آشپزخانه، پت، فصلی، خانه)، دسته‌بندی درختی، ویژگی‌های تخصصی،
  مجوزها (مجوز دامپزشکی غذای حیوانات، پروانه بهداشت ظروف غذایی، استاندارد ملی، CE، IRC، Child-safe، Recyclable)، مدیریت فصلی، گزارش تفکیکی فروش
  (کالاهای مصرفی در مقابل غذایی/شوینده/بهداشتی)، مدیریت موجودی انبار با ابعاد و وزن و محاسبه هزینه ارسال وزنی.
- **UI اختصاصی:** رنگ‌بندی بنفش/نیلی با آیکون و رنگ ویژه هر زیردسته، تگ‌های تصویری «جدید»، «پرفروش»، «فصلی» 🎁، «اقتصادی»، «پریمیوم»، فیلتر چک‌باکسی،

## انتشار روی GitHub Pages

### روش ۱ — انتشار خودکار با GitHub Actions (پیشنهادی)

فایل `.github/workflows/deploy.yml` از پیش آماده است: با هر `push` روی شاخه `main`، بیلد گرفته می‌شود و خروجی در
شاخه `gh-pages` منتشر می‌گردد.

1. کد را روی شاخه `main` پوش کنید:

   ```bash
   git add .
   git commit -m "انتشار نسخه دمو"
   git push origin main
   ```

2. در مخزن به مسیر **Settings → Actions → General → Workflow permissions** بروید و
   **Read and write permissions** را فعال کنید (برای پوش روی `gh-pages`).
3. در **Settings → Pages** گزینه **Deploy from a branch** را انتخاب و شاخه **`gh-pages`** و پوشه **`/ (root)`** را
   تعیین کنید.
4. چند دقیقه بعد، دمو روی نشانی زیر در دسترس است:

   ```
   https://rahmaniho.github.io/Marketer/
   ```

### روش ۲ — انتشار دستی

```bash
npm run build
npx gh-pages -d dist       # شاخه gh-pages را به‌روزرسانی می‌کند
```

### نکات مهم انتشار

- **`base` در `vite.config.ts`** باید با نام مخزن هم‌خوان باشد (`/Marketer/`). برای دامنه اختصاصی،
  `PUBLIC_BASE=/` را در بیلد تنظیم کنید.
- **`public/404.html`** باعث می‌شود مسیرهای مستقیم (مثل `/Marketer/catalog`) به مسیر هش‌دار
  (`/Marketer/#/catalog`) هدایت شوند؛ به همین دلیل مسیریابی این پروژه **HashRouter** است و به تنظیمات سمت سرور
  نیازی ندارد.
- **`public/.nojekyll`** از پردازش فایل‌های شروع‌شده با زیرخط توسط Jekyll جلوگیری می‌کند.
- اگر از دامنه شخصی استفاده می‌کنید، فایل `CNAME` را در `public/` قرار دهید.

## دسترس‌پذیری و PWA

- ساختار HTML معنایی، `aria-*` روی دیالوگ‌ها، دکمه‌ها و سوییچ‌ها، مسیر پیمایش صفحه‌کلید و حالت فوکوس مشخص
- احترام به `prefers-reduced-motion` و `prefers-color-scheme`
- کنتراست رنگی مطابق WCAG AA در تم روشن و تاریک
- قابلیت نصب روی موبایل (Add to Home Screen) با مانیفست فارسی و آیکون‌های اختصاصی
- سرویس‌ورکر سبک: کش دارایی‌های استاتیک و نمایش نسخه آفلاین صفحه اصلی

برای پاک‌کردن کش نسخه قدیمی، مقدار `CACHE_VERSION` در `public/sw.js` را افزایش دهید.

## محدودیت‌های نسخه دمو

- بدون بک‌اند، پایگاه داده و API واقعی (۱۰۰٪ استاتیک و قابل اجرا روی GitHub Pages)
- احراز هویت، درگاه پرداخت، پیامک، واتس‌اپ، ایمیل، نقشه و سامانه مودیان **شبیه‌سازی‌شده** هستند
- سقف اعتبار، موجودی انبار و گزارش‌ها بر پایه داده نمونه محاسبه می‌شوند
- آپلود تصویر کالا و امضای دیجیتال، نمایشی است
- داده هر کاربر فقط در مرورگر خودش ذخیره می‌شود
